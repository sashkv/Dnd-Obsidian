# Командир прибывшего отряда
**Имя:** определить позже.

**Приказ:** изолировать полигон, конфисковать документы, взять под контроль исследователей, задержать всех эльфийских свидетелей.

Не раскрывает военных тайн и не отпускает свидетелей после успешной проверки Убеждения. Предпочитает живых пленных для допроса. Может дать ограниченное время для медицинской помощи, если ситуация контролируется.
